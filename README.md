# AutoTPA

AutoTPA makes teleport requests simpler, faster, and safer.

Manage a trusted-player list, block unwanted requests, or choose to automatically accept every incoming `/tpa` request. Even in global mode, blocked players always take priority.

AutoTPA distinguishes between `/tpa` and `/tpahere`: it only accepts requests where the other player teleports to you, never requests that would teleport you to them.

Main features:

- Trusted-player auto-accept list
- Block list with absolute priority
- Option to accept all `/tpa` requests from online players
- `/tpahere` protection
- Anti-spam cooldown
- In-game menu opened with Right Shift
- Safe and customizable configuration
- Italian and English interface
- Client-side only: no server-side mod required
